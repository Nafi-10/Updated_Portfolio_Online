# Portfolio_Kazi_Jawad

Personal portfolio website for MD Kazi Jawadul Islam.

## Structure
- Root files — Public portfolio website
- `/admin` — Admin dashboard (password protected)

## Admin Access
- URL: `yoursite.netlify.app/admin` (or `/admin` on local server)
- Username: `admin`
- Password: `kji2025`

## How to Update Content
1. Open `/admin` in browser
2. Log in with credentials
3. Navigate to the section you want to edit
4. Make changes and click Save
5. Portfolio updates automatically

## Deployment
Deployed on Netlify. Push to main branch to trigger rebuild.
